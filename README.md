# ENTRENAMIENTO 2.
-Ejercicio de entrenamiento de semana , modulo 1. Riwi 2025.

##  DISEÑO DE PROGRAMA.
Funciones:

1. INGRESAR NOTAS:(El usuario podra poner a cantidad de notas que el usuario desea agregar.)

2. APROBACION DE NOTAS:(Al usuario se le imprimira las notas con un mensaje de aprobada, reprobada.)

3. PROMEDIO DE NOTAS: (El usuario podra pedir que se le imprima el promedio de las notas.)

4. NOTAS APROBADAS & NO APROBADAS: (El usuario podra pedir la cantida de notas que son aprobadas y la que son reprobadas.)

5. NOTA ESPECIFICA: (Al usuario se le pedira que agregue una nota especifica y se determinara si esta agregada anteriormente y cuantas veces.)

6. MENU DE OPCIONES (El usuario tendra un menu de opciones donde seleccionando con un número podra perdir la funcion para que se le ejecute.)

## Nota: cuando lo corra le imprimira los resultados y le volvera a imprimir el menu asi que si, si imprime los datos XD
